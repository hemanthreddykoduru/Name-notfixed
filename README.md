# My-Idea: AI-Native Application Cloud

## Vision
An AI-native application cloud designed for vibe coders. It allows developers to go from an idea generated by AI to a running production application without needing to manage infrastructure complexity (like Docker, VPCs, Kubernetes, etc.). 

It takes inspiration from:
- Vercel (Git-based deployments, previews)
- InsForge (Database, Auth, Storage)
- InstaCloud (Docker-based runtime, branches)

## Architecture
The platform is designed to be modular. The control plane is separate from the infrastructure providers (Compute, Storage, Database, Domain, Deployment).

### Monorepo Structure (pnpm)
- `apps/dashboard`: Next.js frontend for developers.
- `apps/api`: Node.js/Express backend (Control Plane).
- `packages/shared`: Shared TypeScript types and models.
- `infrastructure/`: Local development configuration (Docker, PostgreSQL).

## MVP-0
Our first milestone focuses on the core deployment loop using a local Docker runtime.
The primary goal is to prove we can:
1. Create a project
2. (Soon) Connect a GitHub repo and build it
3. (Soon) Run the application in Docker and expose the URL

**Currently Implemented:**
- pnpm monorepo structure
- Shared data models (`Project`, `Environment`, `Deployment`)
- API endpoints to Create, List, and Get projects
- Basic Next.js dashboard

## Security & Observability
- No direct Docker socket exposure to the browser.
- Deployment statuses are explicitly tracked (QUEUED, BUILDING, RUNNING, etc.).
- AI operations will be performed via structured APIs rather than direct infrastructure modification.
